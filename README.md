# Brian Hitchin — Portfolio

Personal portfolio site built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

All copy (bio, projects, skills, contact info) lives in [`src/data/content.ts`](src/data/content.ts) — edit that file to update the site.

## Deploy

```bash
npm run build
```

Deploys cleanly to [Vercel](https://vercel.com/new) or any Node hosting that supports Next.js.
